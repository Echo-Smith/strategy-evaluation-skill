# WritingAgentBench Public Core v1 数据集卡

- 样本数：72
- 来源：52 条去重合成策略样本 + 20 条重写后的旧版风格样本
- 来源 fixture：20 条，全部为合成证据
- 隐私：全部为 synthetic；不含真实用户 Trace、企业知识库正文、产品私有规则 ID 或实验分区
- 任务分布：abnormal 5，dedupe 8，polish 10，topic 11，writing 38
- 难度分布：L1 24，L2 26，L3 22

## 构建方法

先对两套旧评测资产做字段与风险审计；删除完全重复的策略配对；将含时效事实、体验式口吻、健康风险或产品特有信息的样本排除或重写；最后统一映射到 WABench Schema v1、五项 Rubric 和硬失败门禁。

## 适用范围

用于比较写作 Agent 的选题、成稿、润色、查重和异常输入处理能力。公开分数只代表本合成集，不等同于真实企业业务效果；企业知识库路由、真实用户接受和长期修改负担必须在私有 Holdout 中另行验证。

## 限制

中文公共议题写作占比较高；没有公开真实用户样本；不测试特定企业知识库的召回质量；20 条风格样本经过风险重写，不能作为原产品风格的逐字复刻。
