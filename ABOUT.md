# About / 关于

**中文：** WritingAgentBench 是面向写作 Agent 的公开评测协议与实践案例，强调来源忠实、硬失败、人工接受、修改负担和从评测到发布的完整闭环。Luminbuddy 作为私有企业扩展示例，与公开核心共享协议但不共享敏感数据。

**English:** WritingAgentBench is an open evaluation protocol and product case study for writing agents, covering source fidelity, hard failures, human acceptance, edit burden, and release decisions. Luminbuddy is the private enterprise extension: it shares the contract, not sensitive data.
