# Repository About / 仓库简介

## 中文

**名称**：Strategy Evaluation Skill（策略评测 Skill）

**简介**：面向写作助手的可复现实验评测工具包，覆盖盲评、策略前后对比、Holdout 验证、Badcase 根因分类、知识库来源路由回归和上线门禁。

**适用场景**：选题、写作、润色、查重、异常输入，以及“通用提示词 vs 个人风格记忆”“无来源约束 vs 带来源核验”“一次生成 vs 研究—写作—审校流程”等策略实验。

**核心原则**：单变量对比、开发集与 Holdout 隔离、证据可追溯、评测者与真实用户接受度分开记录、硬失败优先、不得编造评测数据。

## English

**Name**: Strategy Evaluation Skill

**Description**: A reproducible evaluation toolkit for writing assistants, covering blind review, before/after strategy experiments, holdout validation, Badcase root-cause classification, knowledge-source routing regression, and release gates.

**Use cases**: Topic selection, drafting, polishing, duplicate-content checks, abnormal inputs, and controlled comparisons such as “generic prompt vs. personal style memory”, “no source constraint vs. source verification”, and “one-shot generation vs. research—write—review”.

**Core principles**: One-variable-at-a-time comparisons, development/Holdout separation, traceable evidence, separate reviewer and real-user acceptance metrics, hard-failure precedence, and no fabricated evaluation data.
